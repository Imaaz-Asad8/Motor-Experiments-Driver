# Motor-Experiments-Driver

Variable-Speed DC Motor / Fan Controller
 - Built a microcontroller-controlled DC motor system with multiple selectable speed levels.
 - Used PWM to regulate the effective voltage delivered to the motor and control its speed.
 - Used a DRV8833 H-bridge motor driver to safely interface the microcontroller with the higher-current motor.
 - Added push-button controls for changing speeds and software debouncing to prevent unintended multiple inputs.
 - Added decoupling/noise-suppression components to improve reliability while driving the motor. Your current resume summarizes this as PWM control through a DRV8833 with debouncing and decoupling.
